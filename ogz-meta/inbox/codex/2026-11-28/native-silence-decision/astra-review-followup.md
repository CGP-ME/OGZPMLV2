**[P2] The anchor-revision comparison bypasses the native lateness boundary.**

Kraken emits updates to a forming candle using the last-update event time, independently of that candle's scheduled end. The canonical candle start is derived from the end and interval. [Kraken producer](/opt/ogzprime/OGZPMLV2/kraken_adapter_simple.js:1166), [wrapper](/opt/ogzprime/OGZPMLV2/brokers/KrakenIBrokerAdapter.js:398). CandleProcessor accepts a source event up to 120,000 ms old as `on_time`. [Acceptance rule](/opt/ogzprime/OGZPMLV2/core/CandleProcessor.js:978), [current configuration](/opt/ogzprime/OGZPMLV2/config/internals.json:875).

Consider a 1m candle starting at B. Its last native update arrives at B, and another update occurs at B+55s but is delayed in native delivery. A watchdog pass at B+151s sees 151s of silence, beyond the effective 150s limit. Such a pass is reachable because watchdog polling need not align with candle starts; for example, a watchdog started at B-29s polls at B+31s, B+91s and B+151s. [Silence calculation](/opt/ogzprime/OGZPMLV2/run-empire-v2.js:2848).

At that pass, the verifier sets `range.end` to B+31s. Kraken REST can return the already completed anchor ending B+60s: its range filtering uses candle start, and its coverage cursor can cover the requested interval. [REST mapping and coverage](/opt/ogzprime/OGZPMLV2/kraken_adapter_simple.js:359). The new `anchorRevised` comparison has no `brokerAnchor.etime < range.end` condition, while the adjacent later-candle predicate requires that exact maturity boundary. A changed anchor therefore becomes confirmed `native_revision_missing` immediately. [Classification](/opt/ogzprime/OGZPMLV2/run-empire-v2.js:2883), [missing boundary](/opt/ogzprime/OGZPMLV2/run-empire-v2.js:2911).

The update at B+55s is only 96s old when the watchdog convicts it. If it arrives at B+165s, CandleProcessor still classifies its 110s age as `on_time`. If it arrives after the inspection has finished, the native-resumption race checks cannot prevent the earlier quarantine. Alpaca's closed-bar event clock does not create this particular timing shape.

The consequence is an unnecessary symbol halt and potential flattening while the update remains within the configured acceptance window. Quarantine persists the entry halt, attempts recovery, and closes existing trades through the execution path when it has a current price. The completed B candle has age 91s at B+151s, so it can supply an acceptable recovery price under the existing 120s price rule. This can exit an otherwise valid position, incur execution costs or interrupt its strategy. No actual fill or loss amount is claimed. [Quarantine and recovery](/opt/ogzprime/OGZPMLV2/run-empire-v2.js:1701), [price and close conditions](/opt/ogzprime/OGZPMLV2/run-empire-v2.js:1733).
