### 1. THESIS → TRIGGER  
The detector treats **any** candle that crosses the opening‑box high or low as a “sweep” (lines 344‑351) and immediately moves to pattern detection, without checking whether the breakout actually **fails** and re‑reverts.

* **Trigger fires on a simple continuation** – a price that breaks out and then continues upward still satisfies `c(bar) > box.high` (line 344) → `exitSide = 'above'` → pattern search, even though the thesis requires a *failed* break.  
* **Valid thesis state missed** – if a manipulation candle occurs but price never crosses the box (i.e., the break never materialises), the detector never leaves `watching_for_exit` and never produces a signal, so a true liquidity‑grab can be ignored.

> `if (c(bar) > box.high) { … } else if (c(bar) < box.low) { … }` – **LiquiditySweepDetector.js:344‑351**  

---

### 2. TRIGGER → DIRECTION  
Direction is forced by the exit side: `exitSide === 'below'` always yields a **bullish** signal, `exitSide === 'above'` always yields **bearish** (lines 378‑383). This ignores the actual candle shape after the breakout.

* **Counter‑example** – price breaks down (exitSide = 'below'), then a **bearish hammer** appears (low‑wick dominates, but the code still returns `direction: 'bullish'` because the exit side forces bullish).  
  * The hammer‑detection block (lines 378‑381) never checks the exit side’s polarity, so a bearish hammer after a down‑break is mis‑labelled.

> `if (exitSide === 'below') { … return { type: 'hammer', direction: 'bullish', … } }` – **LiquiditySweepDetector.js:378‑381**

### 3. CONFIDENCE MATH  
Confidence is built from a set of **positive** weights, including `sweepReject` (lines 424‑425) which is meant to penalise a “rejection” but instead **adds** to confidence. The sum can exceed 1.0 before the final clamp (line 438), allowing an inflated score.

* **Weight inversion** – `sweepReject` is added when `box.validations.closesInsideRange` is true, but the name suggests a *penalty*. This can push confidence well above the intended range.  
* **No negative weighting** – there is no branch that reduces confidence for a failed rejection, so a weak signal can still pass the `minStrategyConfidence` gate.  
* **Clamp only at the end** – the intermediate sum may be > 1.0, then truncated (line 438), masking the logical error.

> `let confidence = this.config.weights.manipCandle; … if (box.validations.closesInsideRange) confidence += this.config.weights.sweepReject;` – **LiquiditySweepDetector.js:423‑425**

* The orchestrator simply forwards the raw `signal` (line 1431) without applying the contract’s percentages, so the exit hints are effectively ignored.

> `if (pattern.type === 'hammer') { direction = 'bullish'; entry = null; stopLoss = pattern.wickExtreme * bufDn; takeProfit = box.high; }` – **LiquiditySweepDetector.js:412‑417**
