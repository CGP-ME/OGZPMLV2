The plan you entered with is the plan you exit with.

07

Why This Can't Be Knocked Off Over a Weekend

Fifteen months of engineering decisions that only show up when things go wrong — which is exactly when they matter.

Identical Code Paths

Backtest and live trading run the exact same code — only the execution layer swaps. There is no parallel-universe backtest script that behaves differently from production. What you test is literally what runs.

Validated at Every Boundary

Every piece of data crossing a pipeline boundary is schema-validated. Malformed data doesn't propagate — it gets caught at the door. Ghost fills and silent corruption die here.

Restart Integrity

Process dies mid-trade? State is journaled. On restart the engine reconciles its book against the broker's before it touches anything. No orphaned positions, no double entries, no amnesia.

Everything Leaves a Record

The decision ledger writes structured JSONL continuously — every signal, every gate, every order. It's not a report we generate for marketing. It's how the machine works, and it's published automatically.

Your Keys. Your Broker. Your Money.

Your API keys live on your machine — we never see them, never store them, never touch them. We don't know your balance. We don't know your P&L. Nothing relays back to us.
